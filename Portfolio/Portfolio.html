A dynamic platform built with HTML, CSS, JavaScript, and PHP, using MySQL for database management. Users can search for rental properties based on city, price range, and other filters. 🐍 Snake Game

A fun and interactive version of the classic snake game developed using Python's Turtle graphics library. It features real-time movement, collision detection, and increasing difficulty as the snake grows. The game also keeps track of your score and provides a game-over condition when the snake collides with itself or the boundaries.

This console-based Java application simulates a railway ticket booking system. It allows users to check seat availability, enter passenger details, book tickets, and receive a confirmation message. The program uses object-oriented principles to manage different components like seats, passengers, and booking status efficiently.
